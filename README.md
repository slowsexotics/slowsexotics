# Independent developer and creator building UHI

I'm building UHI to make local-first personal AI useful to regular people, especially creators and independent entrepreneurs.

UHI is a personal AI creator assistant in development. The goal is practical help with choosing a next step, organizing creative work and learning from experience, while keeping people in control of their data and tools.

I care about free and open-source AI, privacy and user ownership, local-first systems, creative independence and accessible technology.

Explore [UHI](https://github.com/slowsexotics/uhi), a macOS development preview for local creator profiles, feedback and optional local AI briefings. The current work focuses on security, honest documentation and reliable local setup.
